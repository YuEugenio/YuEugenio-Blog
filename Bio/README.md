## 启动

双击项目根目录的 `启动BioYu.command`，即可启动服务并自动打开浏览器。保持弹出的终端窗口打开，按 Control + C 停止服务；重复双击会打开已运行的预览，不会重复启动。

需要 Node.js 20 或更高版本（本机已安装）。也可以在此目录运行：

```sh
npm run dev
```

打开 http://localhost:5173 。无需 npm install，项目没有第三方运行依赖。资源全部保存在本地。不能直接双击 index.html，着色器加载需要 HTTP 服务。

`npm run build` 生成静态文件到 `dist/`，`npm run preview` 预览构建结果。

## 背景与交互

- `public/assets/bg.png`：当前背景图片，可替换；Safari 如显示旧图，请按 Command + Option + R 强制刷新。
- `src/fluid.js`：WebGL 管线、浮点双缓冲流场、指针及触屏输入、窗口尺寸与滚动同步。
- `src/shaders/fluid.frag`：对流、扩散、鼠标速度注入以及拖尾衰减。
- `src/shaders/light.frag`：四层分形噪声、呼吸、折射位移、RGB 色散、双光源镜面高光、菲涅耳虹彩、暗角及颗粒。
- `index.html`：姓名、简介、教育、经历、研究兴趣与项目内容。
- `src/bio.css`：个人主页排版、教育与经历条目、logo 灰度转彩色的悬停效果和响应式布局。
- `public/assets/logos/`：原始标志及处理版本；页面使用 `jaist-mark.svg`、`sysu-mark.svg`、`hku-mark.svg`、`shumei-mark.svg`，均只保留图形标志。
- `scripts/normalize-logos.mjs`：按可见轮廓生成统一正方形取景框；更新素材后可运行 `node scripts/normalize-logos.mjs` 重新生成。
- `src/main.js`：滚动显现、导航收缩、当前区块高亮；页内跳转使用原生锚点。
- `src/styles.css`、`src/fonts.css`：参考站排版、响应式样式、本地字体。

桌面模拟网格 256×256，移动端 128×128；桌面画布分辨率为 0.75×DPR（DPR 上限 2），移动端 0.6。首屏保留 CG 效果，鼠标平滑系数 0.35、速度衰减 0.85；背景在滚动 0.4 屏后平滑衰减至 18% 亮度，并冻结当前画面。正文区域不再运行流体模拟、光影时间或颗粒动画，也不响应光标；窗口尺寸变化时仅重绘静态画面。返回首屏后恢复交互。

补充浮点帧缓冲检测、WebGL 上下文恢复、隐藏标签暂停以及减少动态效果偏好支持。WebGL 不可用时保留静态背景。

## 来源

初始设计、字体和 GLSL 视觉参数参考用户指定的 https://ochyai.dev 。当前个人简介和经历来自 Jun 提供的信息，背景图片由用户提供。未包含远程运行脚本或跟踪代码。

教育与经历的内容组织参考 https://yiliu.li 。Logo 默认显示 50% 不透明度的纯灰度图，悬停后平滑变为 90% 不透明度的彩色图。灰度层和彩色层使用固定滤镜，通过 `plus-lighter` 混合与同步透明度过渡交叉淡入，避免滤镜和透明度同时变化造成亮度回跳。过渡为 0.4 秒，移出时平滑还原，快速移入/移出从当前值继续。键盘聚焦触发同样效果，鼠标点击后的普通焦点不锁定高亮。底部 Get in touch 模块已移除，首页邮箱保留。

机构标志由用户提供。JAIST 的透明底 PNG 由内置 image_gen 编辑生成，原始文件保留备查；通过 SVG 取景框仅显示右侧圆形校徽，不改变已有圆章图案。中大使用原始 `sysu.png`，保留绿色圆形轮廓内的白底、外围透明，仅显示校徽，不显示 CSE 院徽。早期去白底的 SYSU 版本保留备查，但页面不再使用。港大 `hku-crest.svg` 保留用户提供的校徽原始矢量路径，移除旁边的英文机构名；归一化脚本在生成 `hku-mark.svg` 时，沿原绶带及卷边轮廓补上白色填充，保留校训文字和外部透明区域。页面不设置矩形白色底板。

数美 `shumei-symbol.png` 由内置 image_gen 根据原图制作高清透明底纯图形。提示词要求：仅保留左侧青色/蓝色 M 图形，删除中文与 NEXTRISK 字样，保留轮廓、折叠结构、配色和比例，提升边缘清晰度，不添加阴影、发光或背景。

Logo 作为每条记录右侧的背景层。先测量实际图形的可见边界、排除透明留白，再使用正方形 SVG 取景框归一化，不拉伸图案。四个标志共同使用 `--logo-size: clamp(180px, 20vw, 240px)` 的定位框；600px 以下定位框为 150px，放在文字下方靠右。图形在定位框内以中心为基准 `scale(.5)`，实际可见最长边为定位框的一半，中心位置与文字布局不变。悬停与键盘聚焦仅改变透明度。
