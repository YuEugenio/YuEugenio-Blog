PES Multi-Task Classification: A Project Brief

This article presents the method design, experiment setup, and main results of my undergraduate thesis, with emphasis on the shared 7-task classification line and the structured modeling branches for gingival margin and soft-tissue contour.

March 14, 2026

The full method design follows two lines. The first line is a shared 7-task multi-task classification framework for a unified PES baseline. The second line is structured modeling for gingival margin and soft-tissue contour, used to complement the structural limitations of pure image classification.

1. Research Theme

This work studies automatic Pink Esthetic Score evaluation from intraoral photographs of maxillary anterior implants. PES includes seven sub-items: mesial papilla, distal papilla, gingival margin, soft-tissue contour, alveolar ridge defect, mucosal color, and mucosal texture. The task is therefore formulated as a multi-task classification problem with shared visual representation and task-specific outputs.

The overall design follows a two-layer strategy. The shared classification line provides a unified 7-task baseline. The structured branches separately model the height relation in gingival margin and the contour correspondence in soft-tissue contour.

2. Principle and Implementation of the Shared Classification Line

The shared classification line is built on a unified experiment basis. The dataset contains organized score labels, ROI annotations, and patient-level splits. In total, 332 valid samples contain complete labels for all seven PES tasks and complete ROI information. The input design preserves implant-side local ROI, control-side local ROI, and the full anterior region to jointly model local comparison and global harmony.

2.1 Multi-Task Output Form

The shared classification framework uses a shared encoder, a shared fusion module, and task-specific classification heads. All seven tasks share one visual representation space, while each task outputs a three-class prediction. For task $t$, the output is written as:

$$\hat{\mathbf{p}}_{n,t} = [\hat{p}_{n,t,0}, \hat{p}_{n,t,1}, \hat{p}_{n,t,2}], \qquad \hat y_{n,t}=\arg\max_c \hat p_{n,t,c}$$

This design uses shared representation under limited data while preserving the semantic boundary of each PES sub-item.

2.2 Input Stream Design

The shared classification experiments compare two input modes. The first is two-local, which uses implant-side ROI and control-side ROI. The second is three-stream, which adds a global anterior view. The three ROI types are shown below.

The three-stream design is not a redundant extra view. It explicitly combines local implant-side evidence, mirrored natural-tooth reference, and the global harmony of the anterior region.

2.3 Search Space and Training Setup

The shared classification line starts from an existing baseline built with ResNet50, dual-local inputs, cross-attention fusion, and a linear head. Under one fixed protocol, the experiments compare four structural factors: input organization, backbone model, fusion method, and head design. The total search space is:

$$2 \times 3 \times 2 \times 2 = 24$$
  • Input mode: dual-local or three-stream
  • Backbone: ResNet50, CLIP ViT, or BioMedCLIP ViT
  • Fusion: feature concatenation or cross-attention
  • Head: linear or MLP

All experiments use one shared training protocol: patient-level GroupShuffleSplit, 264 training samples, 68 validation samples, 100 epochs, AdamW, initial learning rate $1\times10^{-4}$, and validation macro AUC as the main model-selection metric.

2.4 Loss and Selection Logic

The seven tasks have different class balances, so the shared classification line uses weighted cross-entropy. For class $c$ in task $t$, the class weight is defined by inverse frequency:

$$w_{t,c}=\frac{N_t}{C\cdot n_{t,c}}$$

The final model is not selected by peak AUC alone. Model selection also depends on the final convergence behavior over the full training schedule.

3. Results of the Shared Classification Line

The 24 architecture runs fall into three convergence types: stable convergence, overfitting collapse, and non-smooth convergence. This classification directly determines the final selection rule.

  • Input organization affects the expression of comparative and global context, and three-stream performs better than local-only inputs.
  • The backbone ranking is CLIP ViT > BioMedCLIP ViT > ResNet50.
  • Fusion and head design affect training stability more strongly than backbone replacement alone.
  • The concat + linear combination gives the most stable convergence under the small-sample setting.

3.1 Three Convergence Patterns

Stable convergence shows smooth late-stage behavior and small peak-to-final gaps, and mostly appears under concat + linear. Severe overfitting appears mainly in complex ResNet50 settings and is characterized by rising validation loss and late-stage AUC degradation. Non-smooth convergence appears in some CLIP and BioMedCLIP settings, where the model reaches a high mid-training peak but does not preserve that peak at the end.

3.2 Final Shared Baseline

The selected final model is CLIP ViT + three-stream + concat + linear. Its validation macro AUC is 0.7004, with a best validation macro AUC of 0.7009. More complex CLIP variants can produce a higher transient peak, but the three-stream concat linear model gives better final convergence quality.

4. Structured Modeling for Gingival Margin

The gingival margin task measures the relative height difference between the gingival zenith of the implant side and the control side. This task has explicit structural meaning, so the thesis introduces a structured quantification pipeline on top of the shared classification baseline.

The pipeline has three main steps. First, it generates stable tooth masks from global ROI guidance and candidate-tooth localization. Second, it estimates the central reference line and the calibrated coordinate system from the segmentation result. Third, it detects the gingival zenith on both sides and maps a normalized height difference to a discrete score.

4.1 Height-Difference Quantification

Let the calibrated vertical coordinates of the implant-side and control-side zenith points be $z_i^\star$ and $z_c^\star$. The absolute height difference is:

$$\Delta h_{\mathrm{abs}} = |z_i^\star - z_c^\star|$$

The main feature selected in the thesis is the smaller-axis-height normalized difference:

$$\delta_h = \frac{\Delta h_{\mathrm{abs}}}{\min(H_i, H_c)}$$

A global threshold search maps this continuous feature to three classes:

$$\hat y_h = \begin{cases} 2, & \delta_h \le \tau_2,\\ 1, & \tau_2 < \delta_h \le \tau_1,\\ 0, & \delta_h > \tau_1. \end{cases}$$

On 240 screened cases, the structured gingival-margin pipeline reaches 0.6042 Accuracy and 0.5307 Macro-F1. On a manually curated subset of 196 good-quality cases, the result improves to 0.6480 Accuracy and 0.5656 Macro-F1. This shows that explicit height features become useful once the reference frame and boundary quality are controlled.

5. Structured Modeling for Soft-Tissue Contour

The soft-tissue contour task depends more on contour curvature, fullness, and overall outline consistency than the gingival-margin task does. For this reason, the thesis builds a contour-based structured analysis pipeline on top of the shared classification baseline.

The pipeline also starts from ROI prompting and SAM segmentation, then extracts the upper contours of both teeth and compares multiple alignment strategies, including rigid translation, local window search, and narrow-band DTW.

5.1 Contour Comparison and Alignment

The basic contour feature is correlation distance. Let the implant-side contour be $c_i(t)$ and the mirrored control-side contour be $c_c(1-t)$. The correlation distance is defined as:

$$d_{\mathrm{corr}} = 1 - \mathrm{corr}(c_i(t), c_c(1-t))$$

For alignment optimization, the thesis further compares rigid translation and narrow-band DTW. The role of narrow-band DTW is not unrestricted warping, but locally constrained correspondence adjustment under order preservation. Its path-smoothness penalty is written as:

$$\phi_{\mathrm{slope}} = \frac{1}{L-1}\sum_{k=2}^{L} \left|(i_k-j_k)-(i_{k-1}-j_{k-1})\right|$$

The shared classification baseline reaches only 0.5548 AUC on the soft-tissue contour task. In contrast, direct contour-correlation comparison reaches 0.6144 Accuracy, rigid translation reaches 0.6208, and narrow-band DTW improves the best Accuracy to 0.6375. This result indicates that soft-tissue contour depends more on contour-level alignment and quantification than on general RGB classification.

6. Conclusion

The experiments support three main conclusions. First, shared multi-task classification is the right main line for PES automatic assessment, and the CLIP ViT three-stream concat linear architecture gives the best balance of performance and stability. Second, the key factor behind stable convergence is not the backbone alone, but the fusion-head combination, and concat + linear is the most reliable structure under the present small-sample setting. Third, gingival margin and soft-tissue contour cannot be fully handled by black-box classification alone. Structured modeling with segmentation, reference-frame correction, zenith detection, contour extraction, and curve alignment provides a clearer explanatory path and stronger supplementary evidence.

The final method design therefore does not force one model family to solve every aspect of the problem. It uses a dual-layer framework: a shared classification main line plus task-specific structured modeling.
