PES Multi-Task Classification: A Project Brief

A compact introduction to my undergraduate thesis project: a modular multi-task framework for automated PES evaluation, from data construction and architecture search to LoRA-based refinement.

March 14, 2026

This project is my undergraduate thesis work. It builds a modular deep-learning framework for PES multi-task classification, with the goal of turning implant-related esthetic evaluation into a more structured, learnable, and experimentally comparable modeling problem.

1. What This Project Is

At the system level, this is not a single fixed model, but a configurable experiment framework. The repository is organized around interchangeable components: backbone encoders, multi-stream inputs, feature-fusion modules, classification heads, loss functions, split strategies, and experiment configs.

From the task catalog and ROI definitions, the project targets automated Pink Esthetic Score related assessment on dental images, especially around implant-centered local regions and their surrounding esthetic context. Instead of predicting only one score, the framework treats the problem as a 7-task classification setup, including mesial papilla, distal papilla, gingival margin, soft tissue contour, alveolar ridge defect, mucosal color, and mucosal texture.

2. What Problem It Tries to Solve

The main challenge is that esthetic evaluation is not naturally a single-label problem. It depends on multiple fine-grained visual factors, and those factors are distributed across both local implant-centered regions and broader global context. That is why this project frames PES evaluation as multi-task learning rather than as a flat one-score classifier.

To support that, the dataset pipeline reads image files together with LabelMe-style ROI annotations and an Excel label table, then builds patient-aware train/validation splits. The input side supports two different views of the problem: a two-local mode using implant ROI plus control ROI, and a three-stream mode that adds a global view.

3. What Has Already Been Implemented

  • A unified dataset builder that parses ROI JSON annotations, reads task labels, constructs patient-group splits, and creates dataloaders under fixed or auto-search split settings.
  • A modular model builder that assembles backbones, feature fusion, and task heads into a configurable PES multi-task model.
  • Support for multiple backbones, including ResNet50, BioMedCLIP ViT, and CLIP ViT.
  • Support for multiple fusion and head choices, including concat vs. cross-attention and linear vs. MLP classification heads.
  • A two-stage experiment workflow: Stage 1 architecture search across 24 configurations, followed by Stage 2 LoRA search across 11 refinement configurations.
  • A full training pipeline with AUC-first checkpoint selection, history export, best-result snapshots, and visualization outputs.

4. What the Current Experiments Show

The most important result so far is that the project is no longer at the “can this be trained?” stage. It has already produced a structured ablation workflow and a clearly selected architecture direction. In the current setup, Stage 1 evaluates 24 model combinations built from 3 backbones, 2 input modes, 2 fusion methods, and 2 head types, while Stage 2 continues with LoRA refinement on the strongest Stage 1 base.

The experiment design was also expanded from an earlier 4-task formulation into a 7-task PES setup, and training was extended to 100 epochs. This matters because the later-stage curves reveal not only which model can peak once, but which structure can keep converging without collapsing.

5. Three Convergence Patterns Observed in Stage 1

After reviewing the Stage 1 curves, I summarize the main outcomes into three convergence cases. This framing became important in my thesis because model selection could not rely on peak AUC alone.

  • Case 1 — Stable convergence: typically associated with concat + linear. Validation loss and AUC move in a smoother direction, with little late-stage collapse.
  • Case 2 — Severe overfitting: seen in many non-concat + linear settings, especially weaker ResNet50 combinations. These models may improve early and then degrade sharply.
  • Case 3 — Non-smooth convergence: validation AUC can peak around the middle of training, fall back, and only later reconverge. This makes the final choice less obvious if one only watches the highest momentary score.

6. Current Model Choice and Why

The current best peak result in the report comes from CLIP + 3 streams + cross-attention + MLP, which reaches an AUC around 0.72. However, the strongest stable final convergence comes from CLIP + 3 streams + concat + linear, whose final AUC is consistently around 0.70.

This distinction is central to the thesis. My conclusion is not simply “choose the model with the highest transient number,” but rather “choose the model that can converge reliably under the full training schedule.” From that perspective, CLIP ViT > BioMedCLIP ViT > ResNet50 is the overall backbone ranking, and adding the global stream is useful not just for noise reduction, but for improving the final representation quality.

7. Why This Thesis Project Matters

What makes this project meaningful is that it moves the work from an isolated model attempt toward a real experimental framework. The contribution is not only “one model got the best score,” but also the design of a reusable pipeline for comparing architectures, input streams, fusion strategies, and parameter-efficient tuning choices under a consistent protocol.

As an undergraduate thesis project, it already has a clear research shape: task formalization, data pipeline construction, modular implementation, ablation design, and evidence-based model selection. In that sense, the project is both a working engineering system and a structured research artifact.
